\# 90-Second Demo – CIFAR-10 Inference System



Hi, this is my CIFAR-10 image classification project.



I built an end-to-end ML system that goes beyond training and focuses on production readiness.



\### What I built

\- A PyTorch-based CIFAR-10 classifier

\- A FastAPI inference service

\- Dockerized deployment with health checks

\- GitHub Actions CI pipeline

\- Clear deployment documentation



\### Architecture

The model is served via a REST API.

Docker packages the inference service.

A `/health` endpoint allows cloud platforms like Kubernetes or Cloud Run to monitor the service.



\### Demo

I can build and run the service using Docker.

Once running, I can access Swagger UI and verify the health endpoint.
